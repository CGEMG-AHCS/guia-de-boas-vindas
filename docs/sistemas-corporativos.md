# Sistemas e Ferramentas
## Principais Sistemas Corporativos

Para apoiar suas atividades na **CGE-MG**, você contará com sistemas corporativos desenvolvidos para facilitar o registro, o acompanhamento e a análise das ações de controle.

Essas ferramentas são essenciais para a rotina institucional, contribuindo para uma atuação **mais eficiente, integrada e orientada a resultados**.

---

## 🎯 Finalidade dos sistemas

Os sistemas corporativos permitem:

- Automatizar processos administrativos  
- Registrar e acompanhar atividades institucionais  
- Apoiar a tomada de decisão  
- Fortalecer a transparência e o controle interno  

---

## 💻 Sistemas disponíveis

A seguir, apresentam-se os principais sistemas utilizados na CGE-MG.

---

## 🗂️ Sistema Eletrônico de Informações (SEI!MG)

O SEI!MG é o sistema oficial para tramitação de processos administrativos eletrônicos no âmbito do Poder Executivo Estadual.

Instituído pelo [Decreto nº 47.228/2017](https://www.almg.gov.br/legislacao-mineira/texto/DEC/47228/2017/?cons=1), seu uso é obrigatório para órgãos e entidades da Administração Pública Estadual.

🔗 **Acesso:**  
- [SEI!MG](https://www.sei.mg.gov.br/sip/login.php?sigla_orgao_sistema=GOVMG&sigla_sistema=SEI&infra_url=L3NlaS8=)

📩 **Suporte:**  
- [Sistema de Suporte AHCS](https://suportecs.cge.mg.gov.br/)  
- coordenacao@cge.mg.gov.br  

---

## 🔍 Sistema e-CGU de Auditorias

Sistema utilizado para apoiar a atividade de auditoria interna governamental.

🔗 **Acesso:**

📩 **Suporte:**
